# Jafsal M A — Portfolio

A clean, responsive portfolio site for GitHub Pages. Built with plain HTML and CSS—no build step or JavaScript dependencies.

## Preview locally

Open `index.html` in a browser, or serve the folder with any static web server.

## Edit the site

- Update the page content and links in [`index.html`](./index.html).
- Adjust colors, typography, spacing, and responsive styles in [`styles.css`](./styles.css).
- Replace the linked PDF with an updated resume, and update its filename in `index.html` if needed.

## Publish with GitHub Pages

1. Push the repository to GitHub.
2. Open the repository’s **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select the branch containing the site and the `/ (root)` folder, then save.

GitHub Pages will publish the site from the repository root.
